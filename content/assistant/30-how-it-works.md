# How omyt works — the loop

omyt runs one loop continuously: source, understand, act, learn. Each pass makes
the next one sharper, which is why a brain that has run for months is worth more
than one switched on yesterday.

## Source

omyt finds the accounts worth knowing rather than only working the ones already
in the CRM. It pulls in market and funding signals, enriches candidates, and
scores them against what has actually converted for this business. Sourcing is a
core function, not an afterthought — the pipeline leaks at both ends, the accounts
you never found and the ones you found and forgot.

## Understand

Every account is read from every signal it gives off: the threads, the pricing
visits, the quiet champion, the sector tailwind. That understanding is held as
meaning and kept current, so the context is already there when a decision is
needed instead of being reassembled by hand each time.

## Act

omyt executes — outreach, follow-ups, reply routing, list-building — inside
guardrails the customer controls. It can run in draft-only mode, where it writes
and queues and a human releases, or with more autonomy as trust builds. Sales and
marketing are the first two functions it runs.

## Learn

Every outcome folds back into the model: won, lost, replied, ignored. A veto
teaches it as much as an approval. Because nothing resets between sessions, the
model compounds toward the goal instead of starting over.

## Why the loop matters

Most tools give you a control without the measurement — they let you act but
never close the loop on whether it worked. omyt's whole design is the closed
loop: it acts, watches the result, and updates. That is the difference between
automation that repeats and a system that improves.

## A worked example

A deal goes quiet. omyt notices the champion re-engaged, that there were three
pricing-page visits in five days, and that the sector has a macro tailwind, and
it surfaces "push this account this week" with that reasoning attached. If the
outreach lands, the pattern is reinforced; if it is ignored, that is recorded
too. Nobody had to reread the thread to find it.
